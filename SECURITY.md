# Security policy

Report cursor restoration, unexpected input suppression, unsafe file handling or other security issues privately through [GitHub Security Advisories](https://github.com/smcnab1/pokelet/security/advisories/new). If the form is unavailable, contact the maintainer using the contact information on [their GitHub profile](https://github.com/smcnab1).

Include the app version, macOS version, impact, expected behaviour and minimal steps to reproduce. Use harmless test files and leave out private data. Keep details private while a fix is being assessed.

Public binaries are pending. The [release checklist](docs/RELEASE_CHECKLIST.md) tracks how the first release will be qualified.
