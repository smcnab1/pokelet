# Code of conduct

Treat other contributors with respect. Discuss the work, credit the people who made it and leave room for disagreement. Harassment, threats, discriminatory language and sharing someone else’s private information are unacceptable.

Contact the maintainer privately through [Sam McNab’s GitHub profile](https://github.com/smcnab1) if you need to report a concern. The maintainer may remove content, restrict participation or block an account to keep the project safe.
