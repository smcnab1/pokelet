# Changelog

This file records release changes. Published notes, downloads and verification details are available on [GitHub Releases](https://github.com/smcnab1/pokelet/releases).

## Unreleased

## [v1.3.1] - 2026-11-26

Build: 7
Title: Pokelet 1.3.1

### Changed

- Move from beta to stable by quitting Pokelet and replacing it with the verified stable download. Your settings and shortcut carry over.
- Studio → Updates checks the signed stable feed. Background checks remain optional. This release sends no usage reports.

## [v1.3.1-beta.2] - 2026-11-23

Build: 6
Title: Pokelet 1.3.1 Beta 5

### Changed

- This build is the first update offered through the signed beta feed. From Beta 4, open Studio → Updates to check for and install Beta 5.

## [v1.3.1-beta.1] - 2026-11-23

Build: 5
Title: Pokelet 1.3.1 Beta 4

### Added

- Check for signed beta updates from Studio → Updates. Pokelet verifies the beta feed, release notes and download before installing an update.
- Automatic update checks are optional. You choose when to install an available update.

### Changed

- Install Beta 4 manually once from the verified GitHub Release to enable beta updates. Existing settings carry over.

## [v1.3.0-beta.1] - 2026-11-23

Build: 4
Title: Pokelet 1.3.0 Beta 3

### Added

- The Updates pane shows your installed version and build and links to GitHub Releases for manual downloads. Public beta builds use manual updates.
- What’s New and version history are available offline in Studio. When you upgrade, Studio offers to show the notes for the new version.

### Changed

- Studio opens with more room for the preview and controls, including when Larger Studio text is enabled.

## [v1.2.0-beta.1] - 2026-11-22

Build: 3
Title: Pokelet 1.2.0 Beta 2

### Added

- Pokelet Studio brings the live preview, character picker and settings into one resizable window.
- Presenter Arm adds a cartoon glove from the bottom of the display while keeping the Mac pointer visible.
- Click sounds can play over identifiable interactive controls. Choose a built-in sound or import a short clip.

### Changed

- Click effects follow primary, secondary and rapid clicks. Choose Companion, Click-only or Replace in Studio.
- Fresh and reset settings use Option–Command–P. Upgrades keep the saved shortcut and settings.

## [v1.1.0-beta.1] - 2026-11-20

Build: 2
Title: Pokelet 1.1.0 Beta 1

### Added

- Choose from four original pointer characters with custom colours, click animations and optional sounds.
- Companion mode keeps the Mac pointer visible. Ordinary pointer use needs neither Accessibility nor Input Monitoring.
